# Quản Lý Chi Tiêu Sinh Viên (Student Expense Tracker)

Chương trình quản lý và theo dõi chi tiêu cá nhân dành cho sinh viên viết bằng ngôn ngữ Python.

---

## 📌 Tính năng chính

1. **Xem hướng dẫn sử dụng**: Nắm rõ các quy tắc nhập liệu và các chức năng của chương trình.
2. **Xem danh sách chi tiêu**: Hiển thị bảng danh sách các khoản chi tiêu hiện có kèm số tiền định dạng chuẩn và danh mục.
3. **Thêm khoản chi tiêu mới**: Kiểm tra dữ liệu đầu vào (tên không rỗng, số tiền phải là số nguyên dương > 0).
4. **Tìm kiếm khoản chi**: Tìm kiếm nhanh theo tên hoặc danh mục (hỗ trợ không phân biệt hoa/thường).
5. **Xóa khoản chi**: Cho phép loại bỏ một khoản chi khỏi danh sách theo tên.
6. **Báo cáo thống kê**: Tổng hợp tổng số khoản chi, tổng số tiền và tỷ lệ phần trăm theo từng danh mục.

---

## 🚀 Hướng dẫn cài đặt & Chạy chương trình

### Yêu cầu
- Python 3.6 trở lên.

### Cách chạy
Mở terminal / command prompt tại thư mục dự án và chạy lệnh:

```bash
python expense_tracker.py
```
